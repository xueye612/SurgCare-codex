
# 模块优先级实施路线图

## 阶段一（MVP） — 必须交付

目标：形成“能用”的 ICU 闭环系统

核心交付项：

- 平台底座：项目骨架、配置、环境
- RBAC：用户 / 角色 / 权限
- 操作审计：`operation_log`（写操作必记）
- 通用字典/枚举（性别 / 状态 / 班次）

ICU 与患者基础：

- `icu_unit` / `icu_bed`
- `patient` / `patient_stay_log`
- 床位状态机与入床/转床/出床流程

护理与医嘱闭环：

- 护理记录：`nursing_record` / `nursing_assessment`（草稿→提交→签名→锁定）
- 补记与作废策略
- 医嘱闭环：`medical_order` / `execution`（执行记录、超时提醒）

告警与驾驶舱：

- 告警中心：`alarm_rule` / `alarm_event` / `handle_log`（ACK/静默/处置/关闭）
- 冷却窗口与聚合（Redis）
- 基础驾驶舱：床位占用率、告警数量/响应时间、今日护理工作量

## 阶段二（增强）

- 引入 MQ（设备事件、告警事件、统计任务）
- 引入时序数据库（vitals trend）
- 院感与质控深化（RCA、整改闭环）
- 排班增强（冲突校验、导出）
- AI 初版：SOFA / 风险评分（Python 服务）

## 阶段三（扩展）

- 波形接入与对象存储（冷热分层）
- 多 ICU / 多院区支持
- 区域质控平台与科研脱敏导出
- 更复杂的告警疲劳治理（聚合、机器学习）
