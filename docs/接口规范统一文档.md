# 接口规范统一文档

## 2.1 统一规范

- Base URL：`/api`
- 版本化：`/api/v1/...`
- 身份认证：JWT（Header：`Authorization: Bearer <token>`）
- 幂等：写接口可支持 `Idempotency-Key`（可选）
- 时间格式：统一使用 ISO8601（包含时区）或时间戳

## 2.2 统一返回结构

成功示例：

```json
{
  "code": 0,
  "message": "success",
  "data": {},
  "trace_id": "xxxx",
  "timestamp": 1700000000
}
```

失败示例：

```json
{
  "code": 40001,
  "message": "validation_error",
  "data": { "field": "name", "reason": "required" },
  "trace_id": "xxxx",
  "timestamp": 1700000000
}
```

## 2.3 分页规范

请求参数：`page`, `page_size`, `sort_by`, `sort_order`

响应结构示例：

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "items": [],
    "page": 1,
    "page_size": 20,
    "total": 132
  },
  "trace_id": "xxxx",
  "timestamp": 1700000000
}
```

## 2.4 列表查询过滤规范

统一使用 query 参数：

- `keyword`
- `status`
- `start_time`, `end_time`
- `icu_unit_id`, `bed_id`, `patient_id`

复杂过滤支持 `filters`（JSON 字符串）或单独 `POST /search`。

## 2.5 文件上传

- `POST /api/v1/files/upload`
- 返回字段：`file_id`, `url`, `mime`, `size`

## 2.6 WebSocket / SSE（实时大屏 / 告警）

- WS 路径：`/ws/v1/icu`
- 订阅 topic 示例：
  - `bed:{bed_id}:vitals`
  - `unit:{unit_id}:alarms`
  - `patient:{patient_id}:risk`
